# Gemini Project Context: Producto API

This project is a RESTful API for managing products, built with Spring Boot and following standard enterprise patterns.

## Project Overview
- **Purpose:** Provide a CRUD (Create, Read, Update, Delete) interface for a product catalog.
- **Main Technologies:**
  - **Java 21**: Utilizing modern Java features.
  - **Spring Boot 3.3.5**: Core framework for the REST API.
  - **Spring Data JPA**: For database abstraction and ORM.
  - **H2 Database**: In-memory database for development and testing.
  - **Lombok**: To reduce boilerplate code.
  - **Jakarta Validation**: For input data integrity.
- **Architecture:** Layered architecture comprising Controllers, Services, Repositories, DTOs, and Entities.

## Domain Model: Producto
The core entity `Producto` includes:
- `id`: UUID (Primary Key, auto-generated).
- `nombre`: String (Required, 2-100 chars).
- `descripcion`: String (Optional, max 500 chars).
- `precio`: BigDecimal (Required, > 0).
- `stock`: Integer (Required, >= 0).
- `activo`: Boolean (Default: true).
- `fechaCreacion` / `fechaActualizacion`: Timestamps managed via JPA Lifecycle hooks (`@PrePersist`, `@PreUpdate`).

## API Endpoints (`/api/productos`)
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/productos` | List all products. |
| GET | `/api/productos/{id}` | Get product by UUID. |
| POST | `/api/productos` | Create a new product. |
| PUT | `/api/productos/{id}` | Update an existing product. |
| DELETE | `/api/productos/{id}` | Delete a product. |
| GET | `/api/productos/paginado` | List with pagination and sorting. |
| GET | `/api/productos/buscar` | Search by name with pagination. |

## Building and Running
- **Build:** `mvn clean install`
- **Run:** `mvn spring-boot:run`
- **H2 Console:** Accessible at `http://localhost:8080/h2-console` (JDBC URL: `jdbc:h2:mem:demodb`, User: `sa`, Password: ` `).

## Development Conventions
- **DTO Pattern:** Use `ProductoRequestDTO` for incoming data and `ProductoResponseDTO` for outgoing data.
- **Validation:** Use Jakarta Validation annotations in DTOs and Entities.
- **Exceptions:** Global error handling is implemented in `GlobalExceptionHandler` using `ResourceNotFoundException`.
- **Database:** Schema is auto-generated by Hibernate (`create-drop`). Initial data is loaded from `src/main/resources/data.sql`.
- **Transaction Management:** Service layer methods are annotated with `@Transactional`.

## Key Files
- `pom.xml`: Project dependencies and build configuration.
- `src/main/resources/application.properties`: Database and server settings.
- `src/main/java/com/example/demo/controller/ProductoController.java`: API entry points.
- `src/main/java/com/example/demo/service/ProductoService.java`: Business logic and DTO mapping.
- `src/main/java/com/example/demo/entity/Producto.java`: JPA entity definition.
